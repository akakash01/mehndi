# 🌿 Mehendi Artist Portfolio Website

A premium, modern, and cinematic portfolio website for professional Mehendi Artists. Designed to showcase artistry, attract bridal clients, and provide a luxury user experience through elegant animations and clean design.

---

## ✨ Overview

This website is built to create a memorable first impression and help Mehendi Artists present their work professionally. The design combines luxury aesthetics, smooth animations, and responsive layouts to deliver a high-end portfolio experience.

### Goals

- Showcase mehendi designs professionally
- Generate booking inquiries
- Build a strong personal brand
- Create an immersive user experience
- Highlight services and portfolio work
